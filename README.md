# 🚗 Parking Lot System

A Java-based Parking Lot Management System designed to handle vehicle entry, exit, and fee calculation efficiently.  
This project demonstrates **object-oriented design**, **data structures**, and **problem-solving skills**.

---

## 📌 Features
- Add vehicles to the parking lot
- Assign parking slots dynamically
- Track vehicle entry and exit times
- Calculate parking fees based on duration
- Handle multiple vehicle types (car, bike, truck)
- Exception handling for invalid operations

---

## 🛠️ Tech Stack
- **Java** (Core logic and OOP design)
- **PostgreSQL** (Database for storing vehicle/slot info)
- **Spring Boot** (REST APIs for integration)
- **Maven** (Dependency management)
